## 🚀 How to Run

### HTML/CSS

Open any `.html` file directly in a web browser.

For files that use external CSS or JavaScript, keep the related files in
the same folder/path as referenced in the HTML.

### JavaScript

JavaScript examples can generally be opened through the browser and
inspected using **Developer Tools → Console**.

### Node.js

Install Node.js, open the project folder in a terminal, and run a
JavaScript file with:

``` bash
node filename.js
```

For example:

``` bash
node "L63 (Node.js).js"
```
